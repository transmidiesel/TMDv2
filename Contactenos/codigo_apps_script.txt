============================================================================
INSTRUCCIONES DE INSTALACIÓN — GOOGLE APPS SCRIPT (TRANSMIDIESEL S.A.S)
============================================================================

Sigue estos sencillos pasos para conectar tu formulario con Google Sheets y tu correo:

PASO 1: CREAR LA HOJA DE GOOGLE SHEETS
1. Entra a https://sheets.google.com y crea una hoja de cálculo nueva en blanco.
2. Nómbrala como quieras (por ejemplo: "Transmidiesel - Contactos Web").

PASO 2: ABRIR EL EDITOR DE APPS SCRIPT
1. En el menú superior de tu hoja de cálculo, haz clic en:
   Extensiones -> Apps Script
2. Se abrirá una pestaña con un archivo llamado "Código.gs".
3. Borra todo lo que esté allí y PEGA EL CÓDIGO que está debajo de esta línea.

PASO 3: CONFIGURAR TUS CORREOS DE DESTINO
1. En las primeras líneas del código verás:
   const CORREOS_NOTIFICACION = [
     "marketing.transmidiesel@gmail.com"
   ];
2. Reemplaza "tu-correo@empresa.com" con el correo o correos donde deseas recibir las notificaciones.

PASO 4: PUBLICAR COMO APLICACIÓN WEB (WEB APP)
1. En la esquina superior derecha de Apps Script, haz clic en el botón azul "Implementar" (o "Deploy") -> "Nueva implementación".
2. En el engranaje (⚙️) "Seleccionar tipo", elige: "Aplicación web".
3. Configura exactamente esto:
   - Descripción: Formulario de contacto web
   - Ejecutar como: "Yo" (tu cuenta de Google)
   - Quién tiene acceso: "Cualquier usuario" (o "Anyone")  <--- ¡MUY IMPORTANTE!
4. Haz clic en "Implementar".
5. Si Google te pide permisos, autorízalos:
   - Selecciona tu cuenta -> Opciones avanzadas -> Ir a (no seguro) -> Permitir.
6. Al finalizar, Google te dará una "URL de la aplicación web" que termina en "/exec".
7. Copia esa URL y pégala en el archivo Contactenos/index.html en la variable:
   const APPS_SCRIPT_URL = "PEGA_TU_URL_AQUÍ";

¡Y listo! Al enviar el primer mensaje desde la página web, el script creará automáticamente
las columnas con los colores corporativos de Transmidiesel, registrará los datos y te enviará un correo.

// 1. CONFIGURACIÓN: CORREOS DE NOTIFICACIÓN
const CORREOS_NOTIFICACION = [
  "tu-correo@empresa.com",     // <-- REEMPLAZA CON TU CORREO PRINCIPAL
  // "comercial@transmidiesel.com"
];

// Nombre de la pestaña donde se guardarán los contactos
const NOMBRE_HOJA = "Contactos Web";

/**
 * Función que crea y formatea automáticamente las columnas en Google Sheets
 */
function inicializarHoja() {
  const libro = SpreadsheetApp.getActiveSpreadsheet();
  let hoja = libro.getSheetByName(NOMBRE_HOJA);
  
  if (!hoja) {
    hoja = libro.insertSheet(NOMBRE_HOJA);
  }
  
  if (hoja.getLastRow() === 0 || hoja.getRange(1, 1).getValue() === "") {
    const encabezados = [
      "Fecha y Hora",
      "Nombre",
      "Correo Electrónico",
      "Teléfono",
      "Asunto / Consulta",
      "Mensaje",
      "Estado"
    ];
    
    const filaEncabezados = hoja.getRange(1, 1, 1, encabezados.length);
    filaEncabezados.setValues([encabezados]);
    
    filaEncabezados
      .setBackground("#0F3E68")
      .setFontColor("#FFFFFF")
      .setFontWeight("bold")
      .setFontFamily("Inter")
      .setFontSize(11)
      .setHorizontalAlignment("center")
      .setVerticalAlignment("middle");
      
    hoja.setRowHeight(1, 38);
    hoja.setFrozenRows(1);
    
    hoja.setColumnWidth(1, 160);
    hoja.setColumnWidth(2, 200);
    hoja.setColumnWidth(3, 230);
    hoja.setColumnWidth(4, 150);
    hoja.setColumnWidth(5, 220);
    hoja.setColumnWidth(6, 400);
    hoja.setColumnWidth(7, 120);
    
    Logger.log("✅ Hoja '" + NOMBRE_HOJA + "' inicializada con éxito.");
  }
  
  return hoja;
}

/**
 * Función principal que recibe las peticiones POST desde la página web
 */
function doPost(e) {
  try {
    const hoja = inicializarHoja();
    
    let datos = {};
    if (e && e.postData && e.postData.contents) {
      try {
        datos = JSON.parse(e.postData.contents);
      } catch (errJson) {
        datos = e.parameter || {};
      }
    } else if (e && e.parameter) {
      datos = e.parameter;
    }
    
    const nombre = (datos.nombre || "No especificado").trim();
    const correo = (datos.correo || "No especificado").trim();
    const telefono = (datos.telefono || "No especificado").trim();
    const asunto = (datos.asunto || "Consulta general").trim();
    const mensaje = (datos.mensaje || "").trim();
    
    const fechaHora = Utilities.formatDate(new Date(), "America/Bogota", "dd/MM/yyyy HH:mm:ss");
    
    hoja.appendRow([
      fechaHora,
      nombre,
      correo,
      telefono,
      asunto,
      mensaje,
      "Nuevo"
    ]);
    
    const ultimaFila = hoja.getLastRow();
    hoja.getRange(ultimaFila, 1, 1, 7)
      .setFontFamily("Inter")
      .setFontSize(10)
      .setVerticalAlignment("middle");
      
    hoja.getRange(ultimaFila, 1).setHorizontalAlignment("center");
    hoja.getRange(ultimaFila, 7).setHorizontalAlignment("center").setBackground("#EBF5FB").setFontColor("#0F3E68").setFontWeight("bold");
    
    const correosValidos = CORREOS_NOTIFICACION.filter(function(c) {
      return c && c.indexOf("@") !== -1 && c.indexOf("tu-correo") === -1;
    });
    
    if (correosValidos.length > 0) {
      enviarCorreoNotificacion(correosValidos, {
        fechaHora: fechaHora,
        nombre: nombre,
        correo: correo,
        telefono: telefono,
        asunto: asunto,
        mensaje: mensaje
      });
    }
    
    return ContentService.createTextOutput(JSON.stringify({
      status: "success",
      message: "¡Mensaje recibido y registrado correctamente!"
    })).setMimeType(ContentService.MimeType.JSON);
    
  } catch (error) {
    Logger.log("Error al procesar contacto: " + error.toString());
    
    return ContentService.createTextOutput(JSON.stringify({
      status: "error",
      message: error.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}
